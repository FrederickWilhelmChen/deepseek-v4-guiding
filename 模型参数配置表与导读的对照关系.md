# config.json 模型参数对照表

## V4 PRO
| 字段                                 |                             Pro 配置值 | 含义                                                                     | 对应导读内容                   |
| ---------------------------------- | ----------------------------------: |------------------------------------------------------------------------|--------------------------|
| `max_position_embeddings`          |                           `1048576` | 最大上下文长度为 1M tokens                                                     | 长上下文主线                   |
| `sliding_window`                   |                               `128` | 滑动窗口大小为 128                                                            | Sliding Window           |
| `compress_ratios`                  | `[128, 128, 4, 128, 4, ... , 4, 0]` | 按层配置压缩比例，4 / 128 交替，128 即 HCA 层，4 即 CSA 层，末尾 0 表示不压缩也就是 Sliding Window | CSA / HCA 分层压缩注意力        |
| `index_topk`                       |                              `1024` | CSA / indexer 选择 top-k 候选块数量                                           | CSA indexer              |
| `index_n_heads`                    |                                `64` | indexer 使用 64 个 head                                                   | CSA indexer              |
| `index_head_dim`                   |                               `128` | 每个 index head 的维度                                                      | CSA indexer              |
| `hc_sinkhorn_iters`                |                                `20` | mHC 中 Sinkhorn 迭代轮数                                                    | mHC 双随机矩阵约束              |
| `n_routed_experts`                 |                               `384` | routed experts 总数                                                      | MoE                      |
| `n_shared_experts`                 |                                 `1` | shared expert 数量                                                       | MoE                      |
| `num_experts_per_tok`              |                                 `6` | 每个 token 激活 6 个 routed experts                                         | activated FLOPs          |
| `hidden_size`                      |                              `7168` | 主干 hidden size，更宽的 Pro 主干                                              | Pro / Flash 规模差异         |
| `num_hidden_layers`                |                                `61` | Transformer 层数                                                         | Pro / Flash 规模差异         |
| `num_attention_heads`              |                               `128` | attention head 数量                                                      | Pro / Flash 规模差异         |
| `moe_intermediate_size`            |                              `3072` | MoE expert 内部 FFN 中间维度                                                 | MoE 容量                   |
| `swiglu_limit`                     |                              `10.0` | SwiGLU 中间值限幅                                                           | 训练稳定性 / SwiGLU clamp     |
| `expert_dtype`                     |                               `fp4` | expert 权重目标 dtype 为 FP4                                                | FP4 QAT / expert 权重低精度   |
| `quantization_config.quant_method` |                               `fp8` | 量化框架仍配置 FP8 e4m3 动态量化路径                                                | FP4 + FP8 混合精度路径         |
| `torch_dtype`                      |                          `bfloat16` | 默认 torch dtype 为 BF16                                                  | 普通计算路径精度                 |
| `vocab_size`                       |                            `129280` | 词表大小                                                                   | tokenizer / embedding 规模 |

## V4 Flash
| 字段                                 |                       Flash 配置值 | 含义                                            | 对应导读内容                   |
| ---------------------------------- | ------------------------------: |-----------------------------------------------| ------------------------ |
| `max_position_embeddings`          |                       `1048576` | 最大上下文长度同样为 1M tokens                          | 长上下文主线                   |
| `sliding_window`                   |                           `128` | 滑动窗口大小为 128                                   | Sliding Window           |
| `compress_ratios`                  | `[0, 0, 4, 128, 4, ... , 4, 0]` | 前两项为0，不启用压缩注意力只走滑动窗口；中间层进入 4 / 128 交替；末尾同样为 0 | CSA / HCA 分层压缩注意力        |
| `index_topk`                       |                           `512` | indexer 选择 top-k 候选块数量，比 Pro 少一半              | CSA indexer / Flash 成本控制 |
| `index_n_heads`                    |                            `64` | indexer 使用 64 个 head，与 Pro 一致                 | CSA indexer              |
| `index_head_dim`                   |                           `128` | 每个 index head 的维度，与 Pro 一致                    | CSA indexer              |
| `hc_sinkhorn_iters`                |                            `20` | mHC 中 Sinkhorn 迭代轮数，与 Pro 一致                  | 双随机矩阵约束                  |
| `n_routed_experts`                 |                           `256` | routed experts 总数，比 Pro 少                     | MoE / Flash 规模缩小         |
| `n_shared_experts`                 |                             `1` | shared expert 数量，与 Pro 一致                     | MoE                      |
| `num_experts_per_tok`              |                             `6` | 每个 token 仍激活 6 个 routed experts，与 Pro 一致      | activated FLOPs          |
| `hidden_size`                      |                          `4096` | 主干 hidden size 明显小于 Pro                       | Pro / Flash 规模差异         |
| `num_hidden_layers`                |                            `43` | Transformer 层数少于 Pro                          | Pro / Flash 规模差异         |
| `num_attention_heads`              |                            `64` | attention head 数量少于 Pro                       | Pro / Flash 规模差异         |
| `moe_intermediate_size`            |                          `2048` | MoE expert 内部 FFN 中间维度小于 Pro                  | MoE 容量                   |
| `swiglu_limit`                     |                          `10.0` | SwiGLU 中间值限幅，与 Pro 一致                         | 训练稳定性 / SwiGLU clamp     |
| `expert_dtype`                     |                           `fp4` | expert 权重目标 dtype 为 FP4                       | FP4 QAT / expert 权重低精度   |
| `quantization_config.quant_method` |                           `fp8` | 量化框架仍配置 FP8 e4m3 动态量化路径                       | FP4 + FP8 混合精度路径         |
| `torch_dtype`                      |                      `bfloat16` | 默认 torch dtype 为 BF16                         | 普通计算路径精度                 |
| `vocab_size`                       |                        `129280` | 词表大小，与 Pro 一致                                 | tokenizer / embedding 规模 |
